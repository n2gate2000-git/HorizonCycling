## 1. 概要

[20260923-GUI化計画書.md](file:///d:/develop/HorizonCycling/docs/20260923-GUI%E5%8C%96%E8%A8%88%E7%94%BB%E6%9B%B8.md) に基づき、従来のコンソールUI（CUI）アプリケーションから、モダンなデスクトップGUIアプリケーション **「HorizonCycling Studio」** への全面刷新および新機能の実装が完了しました。

### 実装された主要機能
1. **既存CUI機能の完全GUI移行**:
   - 大型HUDメーター（パワー、W/kg、実車速、PID目標車速、道路勾配、送信勾配、ケイデンス、ギア、スロットル/ブレーキ開度）
   - モード切替（Simulation / Arcade）、Trainer Difficultyスライダー、ペダルブレーキ切替
   - BLE（FTMS / Cycling Power）、Forza UDP（60Hz）、vJoy のリアルタイム接続ステータス表示
2. **【機能①】走行ログのエクスポート（GPX形式）**:
   - セッション記録（REC / PAUSE / STOP）
   - 緯度・経度・標高・パワー・ケイデンス・心拍・速度を完全収録した標準GPX 1.1ファイルの自動出力（Strava / Garmin Connect即インポート可能）
3. **【機能②】リアルタイム標高プロファイル＆獲得標高トラッカー**:
   - `PositionY` の微小振動ノイズを除去する指数移動平均フィルタ（EMA）
   - ヒステリシス付き累積獲得標高（Elevation Gain: +〇〇m）の積算
   - Chart.js による直近走行区間の標高グラデーションチャート描画
4. **【機能③】リアルタイムマップ追跡（Live Map Tracker）**:
   - リポジトリ内 `map/.tile_cache`（Zoom 5, 8192×8192）のタイル画像を Leaflet.js でオフライン高速描画
   - 自車矢印アイコンのリアルタイム追従および方位角（`Yaw`）連動の滑らかな回転
   - ネオンシアン色の走行軌跡（Polyline）描画
   - `map/fh6_japan_pins.json` からのPOI（名所・イベント）ピン表示

## 4. 起動方法

### GUIアプリケーションの起動
```powershell
# Releaseビルドの実行
./src/HorizonCyclingApp/bin/Release/net8.0-windows10.0.19041.0/win-x64/HorizonCyclingApp.exe

# または dotnet run による起動
dotnet run --project src/HorizonCyclingApp/HorizonCyclingApp.csproj
```

### 操作ガイド
1. **走行開始**: アプリ起動後、上部の **[REC]** ボタンを押すとセッション計測が開始されます。
2. **モード調整**: ヘッダーのドロップダウンで「Simulation」または「Arcade」を随時切り替え可能。
3. **負荷調整**: スライダーでスマートトレーナーの「Trainer Difficulty」をリアルタイムに変更可能。
4. **マップ追跡**: 右ペインの「🗺 リアルタイムマップ追跡」タブで自車の走行ルートや周辺の名所ピンを確認可能。「自車追従: ON」で自車を中心に自動スクロールします。
5. **標高グラフ**: 「📈 標高プロファイル」タブで、走行した高低差の推移を確認可能。
6. **ログ保存**: 走行終了時に **[💾 終了・保存]** ボタンを押すと、`logs/activities/` フォルダへGPXファイルが自動保存され、ワンクリックでフォルダを開いてStrava等へアップロードできます。
