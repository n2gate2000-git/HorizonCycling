# Forza Horizon 6 テレメトリデータの仕様と活用検討

作成日: 2026-09-23

本ドキュメントでは、Forza Horizon 6（およびForzaシリーズ）から出力されるUDPテレメトリデータ（Data Out）の仕様を整理し、位置情報・標高データの取得可否、および「HorizonCycling」における今後の活用方法についてまとめます。

---

## 1. 位置情報・標高の取得可否について

**結論：位置情報および標高（高度）データはリアルタイムに取得可能です。**

現在、本アプリケーション（`HorizonCyclingBridge`）が受信している **324バイトのテレメトリパケット（Dashフォーマット）** には、すでにワールド座標情報が含まれています。
現状は速度や勾配（Pitch）など一部フィールドのみを取り出していますが、パケットの後半部分を展開・パースすることで即座に取得・利用できます。

### 座標・標高のデータ仕様

テレメトリパケットの **オフセット 232〜243 バイト** に、32ビット浮動小数点数（`float` / Little-Endian）として格納されています。

| 項目名 | オフセット | 型 (バイト数) | 単位 | 内容 |
| :--- | :--- | :--- | :--- | :--- |
| **`PositionX`** | 232 | `float` (4) | メートル (m) | ゲーム内ワールド座標 X（東西方向） |
| **`PositionY`** | 236 | `float` (4) | メートル (m) | **ゲーム内ワールド座標 Y（標高 / 垂直高度）** |
| **`PositionZ`** | 240 | `float` (4) | メートル (m) | ゲーム内ワールド座標 Z（南北方向） |

- **標高（高度）**: `PositionY` からミリ秒単位（ゲーム内フレームレート・最大60Hz）で取得できます。
- **平面位置**: `PositionX` と `PositionZ` を用いることで、ゲームマップ上における現在の緯度経度・平面位置を特定できます。

---

## 2. Forza テレメトリパケット（324バイト Dash形式）の全体仕様

Forza Horizon 6 / Horizon 5 / Motorsport 等で出力される「Data Out（Dash形式）」パケットには、車両挙動・環境・レース状況に関する極めて詳細なデータが含まれています。

### パケット構成一覧

```
+-------------------------------------------------------------+
| 0 ~ 231 byte  : Sled データ（運動力学、サスペンション、タイヤ等）   |
+-------------------------------------------------------------+
| 232 ~ 310 byte: Dash 拡張データ（位置座標、車速、入力、ラップ等） |
+-------------------------------------------------------------+
| 311 ~ 323 byte: パディング / 車両拡張情報（合計 324 bytes）     |
+-------------------------------------------------------------+
```

#### ① 基本ステータス & 車両力学
| オフセット | フィールド名 | 型 | 説明 |
| :--- | :--- | :--- | :--- |
| 0 | `IsRaceOn` | `s32` | レース中フラグ（1: 走行中, 0: ポーズ/メニュー等） |
| 4 | `TimestampMS` | `u32` | タイムスタンプ（ミリ秒） |
| 8〜16 | `EngineMaxRpm`, `EngineIdleRpm`, `CurrentEngineRpm` | `f32` x 3 | エンジン最高回転数 / アイドル回転数 / 現在回転数 |
| 20〜28 | `AccelerationX`, `Y`, `Z` | `f32` x 3 | 車両ローカル加速度（X:右, Y:上, Z:前） |
| 32〜40 | `VelocityX`, `Y`, `Z` | `f32` x 3 | 車両ローカル速度ベクトル（m/s、Zが前進速度） |
| 44〜52 | `AngularVelocityX`, `Y`, `Z` | `f32` x 3 | 角速度（ロール、ピッチ、ヨー方向の回転速度） |
| 56〜64 | `Yaw`, `Pitch`, `Roll` | `f32` x 3 | 姿勢角（ラジアン）。**Pitchは道路の斜度（勾配）に直結** |

#### ② 4輪タイヤ・サスペンション（前左 FL / 前右 FR / 後左 RL / 後右 RR）
| オフセット | フィールド名 | 型 | 説明 |
| :--- | :--- | :--- | :--- |
| 68〜80 | `NormalizedSuspensionTravel[4]` | `f32` x 4 | サスペンション沈み込み率（0.0〜1.0） |
| 84〜96 | `TireSlipRatio[4]` | `f32` x 4 | タイヤ縦スリップ率（空転・ロック） |
| 100〜112 | `WheelRotationSpeed[4]` | `f32` x 4 | 4輪それぞれの車輪回転速度（rad/s） |
| 116〜128 | `WheelOnRumbleStrip[4]` | `s32` x 4 | 縁石に乗っているか（1: 接触中） |
| 132〜144 | `WheelInPuddleDepth[4]` | `f32` x 4 | 水たまりの深さ（0.0〜1.0） |
| 148〜160 | `SurfaceRumble[4]` | `f32` x 4 | 路面振動（グラベル・オフロード等の凹凸） |
| 164〜176 | `TireSlipAngle[4]` | `f32` x 4 | タイヤ横滑り角（スリップアングル） |
| 180〜192 | `TireCombinedSlip[4]` | `f32` x 4 | 総合摩擦力（0.0〜1.0以上でグリップ限界） |
| 196〜208 | `SuspensionTravelMeters[4]` | `f32` x 4 | サスペンション実ストローク量（m） |

#### ③ 車両基本設定
| オフセット | フィールド名 | 型 | 説明 |
| :--- | :--- | :--- | :--- |
| 212 | `CarOrdinal` | `s32` | 車種ID（車両固有番号） |
| 216 | `CarClass` | `s32` | クラス（0: D 〜 7: X） |
| 220 | `CarPerformanceIndex` | `s32` | パフォーマンス指数（PI値: 100〜999） |
| 224 | `DrivetrainType` | `s32` | 駆動方式（0: FWD, 1: RWD, 2: AWD） |
| 228 | `NumCylinders` | `s32` | 気筒数 |

#### ④ 位置・運動・車両状態（Dash拡張）
| オフセット | フィールド名 | 型 | 説明 |
| :--- | :--- | :--- | :--- |
| **232** | **`PositionX`** | **`f32`** | **ワールド座標 X（m）** |
| **236** | **`PositionY`** | **`f32`** | **ワールド座標 Y（標高 / m）** |
| **240** | **`PositionZ`** | **`f32`** | **ワールド座標 Z（m）** |
| 244 | `Speed` | `f32` | 総合速度（m/s） |
| 248 | `Power` | `f32` | 出力パワー（W / ワット） |
| 252 | `Torque` | `f32` | トルク（Nm） |
| 256〜268 | `TireTemp[4]` | `f32` x 4 | 4輪タイヤ表面温度 |
| 272 | `Boost` | `f32` | ターボ過給圧 |
| 276 | `Fuel` | `f32` | 燃料残量（0.0〜1.0） |
| 280 | `DistanceTraveled` | `f32` | 累計走行距離（m） |

#### ⑤ レース・操作入力
| オフセット | フィールド名 | 型 | 説明 |
| :--- | :--- | :--- | :--- |
| 284〜296 | `BestLap`, `LastLap`, `CurrentLap`, `CurrentRaceTime` | `f32` x 4 | 各種タイム（秒） |
| 300 | `LapNumber` | `u16` | ラップ番号 |
| 302 | `RacePosition` | `u8` | レース順位 |
| 303〜306 | `Accel`, `Brake`, `Clutch`, `HandBrake` | `u8` x 4 | 操作入力（0〜255） |
| 307 | `Gear` | `u8` | 現在のギア（0: R, 1: N, 2〜: 1速〜） |
| 308 | `Steer` | `s8` | ステアリング角（-127: 左一杯 〜 127: 右一杯） |

## 3. 現状の実装状況（HorizonCyclingBridge）

現在の `ForzaDataPacket.cs` のパース処理では、以下のフィールドを取り出しています。

```csharp
// 現状取得しているデータ
packet.IsRaceOn = BitConverter.ToInt32(bytes, 0) != 0;
packet.TimestampMS = BitConverter.ToUInt32(bytes, 4);
packet.AccelerationX = BitConverter.ToSingle(bytes, 20);
packet.AccelerationY = BitConverter.ToSingle(bytes, 24);
packet.AccelerationZ = BitConverter.ToSingle(bytes, 28);
packet.VelocityX = BitConverter.ToSingle(bytes, 32);
packet.VelocityY = BitConverter.ToSingle(bytes, 36);
packet.VelocityZ = BitConverter.ToSingle(bytes, 40); // 車速計算に使用
packet.Yaw = BitConverter.ToSingle(bytes, 56);
packet.Pitch = BitConverter.ToSingle(bytes, 60);       // 勾配計算・トレーナー負荷に使用
packet.Roll = BitConverter.ToSingle(bytes, 64);
```

すでに `bytes.Length < 324` のチェックを行っており、324バイト全体がパケット受信されているため、**追加の受信用ソケット変更や設定変更なしに、クラスへプロパティを追加するだけで即時利用可能**です。

## 4. HorizonCycling における活用アイデア

位置情報（`PositionX`, `PositionY`, `PositionZ`）および拡張テレメトリを活用することで、以下のような機能拡張が実現できます。

### ① 走行ログのエクスポート（GPX / FIT形式）
- **Strava / Garmin 連動**:
  - `PositionX`, `PositionZ` を実世界の緯度経度（または仮想マップ座標）に変換し、`PositionY`（標高）、車速、パワー（W）、心拍数、ケイデンスとともに GPX や FIT ファイルとして保存。
  - ゲーム内のサイクリング履歴を、Zwiftや実走と同じようにアクティビティ管理サービスへアップロード可能になります。

### ② 獲得標高・高度プロファイルの表示
- **リアルタイムダッシュボード拡張**:
  - `PositionY` の累積上昇量をトラッキングし、「本日の獲得標高（Elevation Gain: +〇〇m）」をコンソールまたはUI上に表示。
  - 「今、標高〇〇m地点を走行中」というヒルクライム実感を強化。

### ③ リアルタイムマップ追跡（Live Map Tracker）
- **現在地のマッププロット**:
  - リポジトリ内にある `map/fh6_japan_map_cropped_4608x5632.png` やピン情報（`fh6_japan_pins.json`）と `PositionX/PositionZ` をマッピング。
  - ブラウザやセカンドモニター上に「日本マップ上のどこを走っているか」をリアルタイム表示。

### ④ 路面環境フィードバック（将来的なトレーナー・ハプティクス連動）
- `SurfaceRumble`（路面振動）や `WheelInPuddleDepth`（水たまり）を取得することで、グラベル（未舗装路）や石畳、ウェット路面に入ったことを検知し、トレーナーの路面フィール再現やコントローラー振動に反映。

---

## 5. まとめ

Forza Horizon 6 のテレメトリからは、**位置情報（X, Z）および標高（Y）を高精度かつ高頻度で取得可能**です。
これらはサイクリング体験を「単にZwift代わりに車を動かす」だけでなく、「広大なオープンワールドを実際に旅し、ログを残す」という本格的なバーチャルサイクリングプラットフォームへと進化させるための強力な基盤となります。
